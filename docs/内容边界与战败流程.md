# 内容边界与战败流程

---

## 一、我写什么，不写什么

**写**：

- 暗示——「床已经准备好了」「这条走廊没有出口」
- 威胁——「别想逃」「妳会一直被留在这里」
- 黑场前的最后一句
- 反派的态度、语气、节奏
- 系统的提示文本（「薇薇的手被束缚住了！」这类）

**不写**：

- 具体身体描写
- 具体过程描写
- 任何需要「想清楚细节」才能落笔的段落

游戏里所有需要这类内容的位置，一律留空，由你填。

> 这条边界不是靠措辞绕过去的，是内容本身的性质决定的。
> 我写氛围和威胁，你写具体。分工清楚，互不越界。

## 二、战败流程

**只用在 Boss 战**。小怪战败走引擎默认的游戏结束。

### 结构

```
◆文字：果然还是太勉强了。 / 别担心。 / 很快就会习惯的。
◆呼叫公共事件：5「战败处理」
```

### 公共事件 5「战败处理」

```
◆画面淡出
◆等待 30 帧
◆注释：【CG-B-01】 战败 CG 占位。在这里插入图片 / 演出。
◆显示选项：读取存档 / 回到主界面
  ├ 读取存档  → 打开读档画面
  └ 回到主界面 → 返回标题
```

### 你要填的地方

**唯一一处**：公共事件 5 里那行注释 `【CG-B-01】`。

替换成你的演出即可：

```
◆注释：【CG-B-01】 战败 CG 占位。在这里插入图片 / 演出。
↓ 改成
◆显示图片：#1, CG_B01, 左上 (0,0), 100%
◆等待 60 帧
```

图片放 `img/pictures/CG_B01.png`。

如果有多个 Boss，就复制这个公共事件，改编号 `【CG-B-02】`、`【CG-B-03】`。

### 在 Boss 事件里怎么接

```
◆战斗处理：Boss队伍, 不可逃跑, **可以失败**   ← 关键：勾「可以失败」
◆胜利时
  ◆（剧情）
◆失败时
  ◆（最后一句威胁台词）
  ◆呼叫公共事件：战败处理
```

「可以失败」必须勾上，否则引擎会直接走游戏结束画面，轮不到公共事件。

## 三、Boss 战的写法

第一章的「祝祝修女」是模板（地图 2，(12, 2)）：

```
◆祝祝修女：终于抓到妳了，净化者。
◆祝祝修女：其余的人会变成祝。
◆祝祝修女：只有妳——会被留下来。
◆祝祝修女：别想逃。
◆祝祝修女：这条走廊没有出口。
◆祝祝修女：床已经准备好了。
◆战斗处理：祝祝修女, 不可逃跑, 可以失败
  ├ 胜利 → 修女倒下 / 开关「第一章通关」ON
  └ 失败 → 果然还是太勉强了…… → 战败处理
```

照着这个结构复制，改台词和队伍就行。

## 四、色情攻击技能怎么造

**原则**：文案写到「做了什么」为止，不写怎么做的。

| 好 | 不好 |
|---|---|
| `薇薇 被塞上了某个东西！` | （具体描写） |
| `薇薇 被摸了一把。` | （具体描写） |
| `薇薇 的手被按住了！` | — |

现有的 10 个束缚系技能就是模板，都在数据库里：

- 备注栏 `<lewd:N>` 控制色情条涨幅
- `<fail1>` ~ `<fail5>` 控制各束缚等级的文案
- `<okmsg>` 控制回避文案

复制一个改改就能用，**不用动代码**。

详细规范见 [技能填写规范.md](技能填写规范.md)。

## 五、数值怎么定

现在都是占位值，没调过平衡。参考区间：

| 项 | 建议范围 |
|---|---|
| 小怪 `<lewd:N>` | 10–20 |
| Boss `<lewd:N>` | 20–35 |
| 色情条上限 | 100（固定） |
| 高潮后回落 | 30（固定） |
| 束缚等级 | 0–5（固定） |

**别太急**。一回合就满条会让系统失去节奏。
按现在 25 的涨幅，要 4 次命中才高潮，差不多是 3–4 个回合——这个节奏是合理的。
