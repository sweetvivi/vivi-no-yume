## 已知坑

| 坑 | 说明 |
|---|---|
| `create_map_event` 默认 `priority: below` | 按确认触发的事件必须显式设 `priorityType: 1`，否则按 OK 无反应 |
| 事件第 2 页的 `selfSwitchA` | 建的时候会带 `selfSwitchA: true` 但 `selfSwitchValid: false`，导致第 2 页永远优先。**跑 `tools/fix_pages.py` 批量修**，别手改 |
| Boss 死亡后的那一页会挡路 | 第 2 页默认 `priority: same` + 有立绘，玩家过不去。Boss 事件建完必须把第 2 页设成 `below + through + 无图形` |
| 设开关后立刻 startEvent | 地图没刷新，事件还是旧页。要等 0.5 秒以上 |
| 测试时事件挂起 | 台词播完在等玩家按键，后面的事件指令还没执行。**验证开关类逻辑用 `advanceText` 而不是 `press ok N 次`** |
| `validate_project` 报 601/603 | 误报。战斗分支的合法指令码，校验器未收录 |

## 建完多页事件的固定流程

1. 建事件
2. 跑 `python tools/fix_pages.py`（修 selfSwitch 条件）
3. Boss 事件：把死亡后那一页设成 `below + through + 无图形`
4. 跑 playtest 验证，用 `advanceText` 推进
