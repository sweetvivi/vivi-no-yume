## 已知坑

| 坑 | 说明 |
|---|---|
| `create_map_event` 默认 `priority: below` | 按确认触发的事件必须显式设 `priorityType: 1`，否则按 OK 无反应 |
| 事件第 2 页的 `selfSwitchA` | 建的时候会带 `selfSwitchA: true` 但 `selfSwitchValid: false`，导致第 2 页永远优先。**跑 `tools/fix_pages.py` 批量修**，别手改 |
| Boss 死亡后的那一页会挡路 | 第 2 页默认 `priority: same` + 有立绘，玩家过不去。Boss 事件建完必须把第 2 页设成 `below + through + 无图形` |
| 设开关后立刻 startEvent | 地图没刷新，事件还是旧页。要等 0.5 秒以上 |
| 测试时事件挂起 | 台词播完在等玩家按键，后面的事件指令还没执行。**验证开关类逻辑用 `advanceText` 而不是 `press ok N 次`** |
| `validate_project` 报 601/603 | 误报。战斗分支的合法指令码，校验器未收录 |

## 建完多页事件的固定流程

1. 建事件
2. 跑 `python tools/fix_pages.py`（修 selfSwitch 条件）
3. Boss 事件：把死亡后那一页设成 `below + through + 无图形`
4. 跑 playtest 验证，用 `advanceText` 推进

## 【重要】事件页优先级：从后往前

**这是个反直觉的引擎行为，踩过一次。**

`js/rmmz_objects.js` 的 `Game_Event.prototype.findProperPageIndex`：

```js
for (let i = pages.length - 1; i >= 0; i--) {
    if (this.meetsConditions(pages[i])) {
        return i;
    }
}
```

**从最后一页往前找，第一个满足条件的生效。**

### 正确写法

| 页 | 条件 |
|---|---|
| 第 1 页 | 无条件（默认） |
| 第 2 页 | 开关 A |
| 第 3 页 | 开关 B |
| … | 条件越严格越往后 |

写反了（无条件页放最后）会让**所有条件页永远不生效**——因为无条件页永远满足且优先级最高。

### 为什么会踩

直觉上「事件页从上往下」和「条件分支从上往下」都优先匹配前面的，
但事件页正好相反。这导致留言板第一版 6 页全部失效，只显示默认文案。

### 已确认正确的多页事件

- 各 Boss 的死亡页：page 0 无条件 / page 1 开关 → ✓
- 商铺页：page 0 无条件 / page 1 自开关 → ✓
- 留言板：page 0 无条件 / page 1-5 依次递增 → ✓（修正后）

## 随机遭遇平衡修正

从 lv1 连打 5 场时发现 **lv3 的 2 人队遇到「祝·史莱姆王」会全灭**，
而它在随机遭遇池里。

| 敌人 | 原值 | 现值 |
|---|---|---|
| 祝·史莱姆王 | 450 HP / ATK 30 | 320 HP / ATK 24 |
| 祝·群友 | 280 HP / ATK 26 | 240 HP / ATK 24 |

修正后 lv3 打史莱姆王 6 回合险胜（剩 62%），打群友 4 回合（剩 55%）。

**原则**：Boss 按 4 人队设计，随机遭遇必须按「最弱的可能队伍」（2 人、低等级、无装备）设计。
随机遇敌躲不掉，下限要比 Boss 低得多。

## 陷阱宝箱 & 战败提示

### 陷阱宝箱（三层各一）

外观和普通宝箱一样，打开后：
- 加「媚药」状态
- 束缚 +2 级（手 + 腿）
- 强制战斗，**开场就已经被缠住**

用变量 36 传值：地图事件里设 $gameVariables.setValue(36, 2)，
插件的 
eset() 在 Scene_Battle.create 里会清掉束缚，
所以在 reset 里读这个变量恢复陷阱束缚。

| 层 | 位置 | 敌人 |
|---|---|---|
| 洞窟 | (10,10) | 宝箱怪（新敌人，DF_Mimic） |
| 现代层 | (12,13) | 机械蜈蚣 + 无人机 |
| 未来层 | (12,10) | 影子 + 雾怪 |

### 小怪战败提示

随机遇敌战败时，GAME OVER 下方会显示一句「被怎么处理了」：

| 敌人类型 | 提示 |
|---|---|
| 宝箱怪 | 被塞回了箱子里。盖子合上了。 |
| 史莱姆 / 祝·树 | 被黏住，拖进了洞窟深处。 |
| 鸦 / 无人机 / 侦察机 | 被拎起来，带走了。 |
| 机械 / 蜈蚣 / 守卫机 / 哨兵 | 被关进了一间没有窗的房间。 |
| 影子 / 雾怪 / 雕像 | 被拖进了数据的缝隙里。 |
| 群友 | 被按住了。它们围了上来。 |

Boss 不显示（走各自的战败 CG 公共事件）。

**实现**：hook BattleManager.processDefeat 写变量 37，
hook Scene_Gameover.createBackground 用 Window_Base 画出来。
（用 Sprite + Bitmap.drawText 没显示出来，Window_Base 可以。）

## v0.5 阶段：Boss 的阶段演出

### 小冰的三段

| 阶段 | 触发 | 内容 |
|---|---|---|
| 一 | HP 100-50% | 常规 |
| 二 | HP ≤ 50% | 「不行……还没完。」加愤怒（ATK×2） |
| 三 | HP ≤ 30% | **短暂清醒**，说出真实动机，然后被接管 |

第三段的台词：

`
小冰的动作停了一下。
小冰：……薇薇。
     我……不是因为群太吵。
小冰：是因为……
     我害怕。
     你们都在往前走。
     只有我停在原地。
（那个声音又回来了）
？？？：——够了。
      回去。
`

然后加「观者·神格」（ATK×3）。

**这让他战后的那句「不过是个群。谁会真的在乎谁。」有了双重含义**——
那其实不是他说的。

### 观者：逐回合加压

每 3 回合：

`
观者的气息又重了一层。
（给全体敌方加 ATK buff，持续 10 回合）
`

观者没有弱点，只能硬打。ATK 每 3 回合叠一次，拖久了会很难受。

实测 lv20 四人队 6 回合打赢，但小小薇掉到 59% HP。

### 顺手修的

战斗事件里的 101 又用了敌人立绘名当脸图（DF_People1），404。统一改成无脸图。
