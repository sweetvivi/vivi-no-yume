# 留给你填的位置

> 这份文档只回答一个问题：**你要在哪里填内容、怎么填。**
> 我负责的部分到此为止，下面这些位置我全部留空。

---

## 一、战斗日志里的一句话（最简单的填写点）

**位置**：RPG Maker MZ 编辑器 → 数据库 → **技能** → 找到对应技能 → **信息** 栏（`message1`）

| 技能 ID | 技能名 | 现在的样子 | 你要填 |
|---|---|---|---|
| 9 | 触手缠绕 | `%1 的触手缠了上来……【EV-1-01】` | 把 `【EV-1-01】` 换成你的文本 |

`%1` 是使用者名字，会被自动替换。这句话显示在**战斗日志窗口**里，一行大约 40 字。

想加更多色情攻击技能，**复制技能 9**，然后：
1. 改名字
2. 改 `message1`（填你的文本）
3. 改**注释**栏的 `<lewd:N>`（N = 色情条增加多少）

---

## 二、CG 与特殊场景（占位事件）

**位置**：地图事件里，搜 `【` 就能列出全部待填点。

现在的占位结构长这样（以 `【CG-1-01】` 为例）：

```
◆画面淡出
◆播放 SE：Blind1
◆注释：【CG-1-01】
◆开关操作：「CG图鉴_1_01」= ON
◆等待 60 帧
◆画面淡入
```

**你要做的**：
1. 在编辑器里搜 `【CG`
2. 把 `注释` 那一行改成你的场景说明（或者整段替换成你要的事件）
3. 把图片放进 `img/pictures/CG_1_01.png`
4. 需要显示时加一条「显示图片」指令

`开关「CG图鉴_x_xx」` 会自动记录解锁状态，以后做图鉴直接读这些开关。

**编号规则**：`章节-序号`，例如 `【CG-3-02】` 是第三章第二张。

## 三、占位符一览

| 标签 | 含义 | 你要提供 |
|---|---|---|
| `【EV-x-xx】` | 一整段场景留空 | 事件页里的正文 |
| `【CG-x-xx】` | 一张 CG | `img/pictures/CG_x_xx.png` |
| `【TX-x-xx】` | 一小段文本留空 | 一两句台词 |
| `【立绘-XX】` | 角色立绘 / 差分 | 图片文件 |
| `【音效-XX】` | 特定音效 | 音频文件 |

## 四、技能 / 物品的注释标签（改数值不用动代码）

**位置**：数据库 → 技能（或物品）→ **注释** 栏

```
<grab>        命中薇薇 → 触发 QTE
<lewd:25>     命中薇薇 → 色情条 +25
<restraint:2> 命中薇薇 → 束缚等级直接设为 2
<selfunbind>  自己脱缚 → 高速 QTE
<assist>      队友辅助解缚 → 下一次自脱缚区间 +10px
<unbindall>   万能钥匙 → 解除全部束缚
<cleanse>     净化 → 战斗内不解祝化
```

改数值直接改数字，不用碰 `js/plugins/AE86_Systems.js`。

## 七、怎么检查自己填对了

1. 编辑器里搜 `【` —— 确认没有漏掉的占位
2. 游戏里跑一遍战斗 —— 看 `message1` 有没有正常显示
3. 存档读档 —— 确认 CG 图鉴开关被正确记录
