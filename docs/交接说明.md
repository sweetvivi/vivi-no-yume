## 六、已知坑（改东西前必看）

| 坑 | 说明 |
|---|---|
| **事件页优先级是从后往前** | `findProperPageIndex` 倒序遍历。无条件页放**最前面**，条件越严格越往后 |
| selfSwitch 条件 | 建事件时容易写成 `selfSwitchA: true`，正确的是 `selfSwitchValid: true` + `selfSwitchCh: 'A'`。跑 `tools/fix_pages.py` 批量修 |
| action_button 的 priorityType | 为 0 时按确定键**没有反应**。跑 `tools/check_priority.py --fix` 批量修 |
| Boss 死亡页 | 必须设成 `below + through + 无图形`，否则挡住去路 |
| 装备的 atypeId | `canEquipArmor` 检查的是 **atypeId**（需要职业 trait 授权），不是 etypeId 槽位 |
| 伤害公式 | `evalDamageFormula` 会把负值 clamp 到 0，做不了「给敌人回血」 |
| 测试 | 用 `advanceText` 推进，不要 `press ok N 次`（会漏掉后续指令） |
