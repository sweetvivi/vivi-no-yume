# 技能填写规范（敌怪束缚系）

> 这份文档说明**每一栏填什么**，以及**文案标签怎么用**。
> 照着现成的 10 个技能改就行。

---

## 一、两种提示的分工

一次攻击会显示**两次**文字，来源不同：

| 时机 | 来源 | 例子 |
|---|---|---|
| **发起攻击时** | 技能的「信息」栏 `message1` | `祝·史莱姆 的触手缠了上来……` |
| **QTE 判定后** | 技能「备注」栏的文案标签 | `薇薇 回避了这次攻击。` / `薇薇 的手被束缚住了！` |

所以：

- `message1` 写**攻击动作**，不写结果。命中、打空、回避都一样显示。
- 结果文案全部放在**备注**栏，由 QTE 判定决定显示哪一句。

## 二、备注栏标签速查

```
<grab>          触发 QTE 回避判定（束缚系技能必须写）
<lewd:25>       命中时色情条 +25
<restraint:N>   命中时束缚等级直接设为 N（不判定）

<okmsg:……>      QTE 成功（回避）时显示
<fail1:……>      失败且束缚升到 Lv1（手）
<fail2:……>      失败且束缚升到 Lv2（腿）
<fail3:……>      失败且束缚升到 Lv3（嘴）
<fail4:……>      失败且束缚升到 Lv4（眼）
<fail5:……>      失败且束缚升到 Lv5（完全）
```

**不写的标签会走默认文案**：

| 标签 | 默认 |
|---|---|
| `okmsg` | `薇薇 回避了这次攻击。` |
| `fail1` | `薇薇 的手被束缚住了！` |
| `fail2` | `薇薇 的腿被束缚住了！` |
| `fail3` | `薇薇 的嘴被堵上了，无法吟唱！` |
| `fail4` | `薇薇 的眼睛被遮住了！` |
| `fail5` | `薇薇 被彻底束缚住了……` |

> 判定失败时束缚等级**只升一级**。所以「失败升到 Lv2」时显示的是 `fail2`，
> 不是 `fail1`。写的时候按**结果等级**来对应。

## 三、其他栏位

| 栏位 | 填什么 |
|---|---|
| **名称** | 技能名 |
| **图标** | 挑一个 |
| **说明** | 只显示在菜单/技能列表，战斗时不显示 |
| **技能类型** | **无**（敌人技能不归魔法/特殊，不会被沉默封印） |
| **MP / TP** | 0 |
| **范围** | 敌方单体 |
| **使用场合** | 战斗画面 |
| **命中类型** | **物理攻击**（保留回避机制，见下节） |
| **效果** | 一般加「附加状态：发情 60%」之类 |
| **备注** | 上面那套标签 |

### 关于命中类型

**保持「物理攻击」**，不要改必中。

实测命中率 = 敌人命中 0.95 × 薇薇回避 0.05 ≈ **90%**。
也就是约 10% 的回合「攻击提示显示了但没触发 QTE」——这是**有意的**，
回避机制留着，之后要靠装备拉开差距。

**后续的服装 / 回避设计**（还没做）：

| 装备类型 | 回避 | 说明 |
|---|---|---|
| 轻薄（裙装、袜类） | **高** | 提升敏捷 / 回避 |
| 普通 | 中 | — |
| 重甲（铠甲） | **低 → 0** | 有重量，甚至完全无法回避 |

实现方式：给防具加 `xparam 1`（回避率）的 trait，
重甲给负值。这样命中率会自然跟着装备变化，不用改技能。

## 五、想加新技能怎么办

1. 在数据库里**右键复制**一个现成技能
2. 改**名称**、**图标**
3. 改**信息**栏的 `message1`（攻击动作）
4. 改**备注**栏：`<lewd:N>` 调数值，`<failX>` 换成你要的文案
5. 想让某一句不出现，删掉那个标签即可，会自动走默认

**不需要动代码。**

## 六、想改机制数值

改 `js/plugins/AE86_Systems.js` 顶部的 `CFG.qte`：

```js
baseZone: 96,          // 法师基础判定区间
swordZone: 150,        // 魔剑士基础
minZone: 10,           // 下限
zonePerLewd: 0.5,      // 色情条每点缩减
zonePerRestraint: 14,  // 束缚每级缩减
assistBonus: 10,       // 队友辅助加成
frames: 180,           // 超时帧数
selfMulMin: 2,         // 自脱缚最低倍率
selfMulMax: 5,         // 自脱缚最高倍率
```
