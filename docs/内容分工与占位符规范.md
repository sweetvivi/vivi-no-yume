# 内容分工与占位符规范

## 一、分工

| 谁 | 做什么 |
|---|---|
| **我（代理）** | 数据库、地图、事件逻辑、战斗、系统、非露骨剧情文本、占位符骨架、可玩性验证 |
| **你** | 成人向场景的正文、CG 图片、立绘差分、你想保留的具体描写 |

我写的内容止步于：**暗示、威胁、氛围、黑场、跳转**。
具体内容由你在占位处填，我不读、不改、不补。

## 二、占位符约定

事件里出现的占位一律用方括号标签，方便你全局搜索：

| 标签 | 含义 | 你要提供的 |
|---|---|---|
| `【CG-01】` | 一张 CG | `img/pictures/CG_01.png` |
| `【EV-01】` | 一整段场景留空 | 事件页里的正文 |
| `【TX-01】` | 一小段文本留空 | 一两句台词 |
| `【立绘-XX】` | 角色立绘/差分 | 图片文件 |
| `【音效-XX】` | 特定音效 | 音频文件 |

编号规则：`章节号-序号`，例如 `【CG-3-02】` 是第三章第二张。

## 三、占位在游戏里怎么实现

每个占位点用同一个「留空事件」结构，保证行为一致：

```
◆画面淡出（黑）
◆播放音效（SE）
◆注释：【CG-3-02】  ← 你在编辑器里一眼能搜到
◆打开开关：「CG图鉴_3_02」
◆等待 60 帧
◆画面淡入
◆（回到剧情）
```

好处：
- 你在编辑器里搜 `【` 就能列出全部待填点；
- 「CG图鉴」开关自动记录，皮老智的图鉴系统可以直接读这些开关，不用另外做解锁逻辑；
- 我改剧情时不会碰你的正文，你的正文也不会被我的批量操作覆盖。

## 四、我这边的内容边界

这部分写清楚，省得来回试探：

1. **暗示可以写**。威胁、居高临下的台词、"抓起来好好教育（爱心）"、黑场前的最后一句——这些都写。
2. **具体描写不写**。不写身体、不写过程、不写细节。占位处直接跳。
3. **角色标签**：设定集里的「小萝莉」统一替换为「小蛋糕」，不再含儿童化标签。
   其余角色按中性处理（未明确写「一个女生」的），特殊说明的按说明走。详见设定圣经 3.0。
4. **头像的用法**：素材是二次元 QQ 头像，直接裁成脸图使用，无肖像问题。

## 五、头像 → 素材的技术现状

现有 41 张头像，尺寸不统一：

| 尺寸 | 数量 | 处理 |
|---|---|---|
| 640×640 | 32 张 | 直接裁成 144×144 脸图 |
| 639×640 / 640×639 | 3 张 | 裁边 1px 后同上 |
| 438×438、300×300 | 2 张 | 放大到 144 再裁 |
| 329×301、328×341、323×348 | 3 张 | 非正方形，需补边 |
| 193×192 | 1 张 | 太小，需放大 |

RPG Maker MZ 需要：
- **脸图** `img/faces/`：576×288 的整张图，内含 4×2 个 144×144 格子
- **行走图** `img/characters/`：每人 3×4 帧（或直接复用脸图做立绘）

头像大多是方图，做**脸图**没问题；做**行走图**需要另画全身，**现阶段先占位**，
之后用 RPG Maker MZ 自带的生成器（`RPG.Maker.MZ/generator`）或外部制作。
