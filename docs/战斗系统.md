# 战斗系统设计

> 实现文件：`js/plugins/AE86_Systems.js`
> 数据：状态 4–15、技能 3–9、敌人 1、队伍 1

## 一、形态切换（法师 ⇄ 魔剑士）

| 形态 | ATK | MAT | 说明 |
|---|---|---|---|
| **法师**（默认） | ×0.35 | 正常 | 近战极弱，魔法伤害高 |
| **魔剑士** | ×2.0 | 正常 | 近战强化 |

- 用技能 **「剑心·转」**（技能 6，消耗 30 TP）切过去。
- TP 来源：施放光之矢 +15、成功挣脱 QTE +20、受伤也会积累。
- 状态 ID：`4 魔剑士形态`。
- 实现：`Game_Actor.prototype.param` 对 actor 1 的 `paramId === 2`（ATK）乘倍率。

> 待定：魔剑士形态目前**不会**自动变回法师。要不要加回合数限制，等你定。

## 二、束缚系统

| 等级 | 状态 ID | 效果 |
|---|---|---|
| 0 | — | 自由 |
| 1 | 5 束缚·手 | 不能普攻、不能用道具、不能切换形态 |
| 2 | 6 束缚·腿 | 不能逃跑（`canEscape` 返回 false） |
| 3 | 7 束缚·口 | 不能使用魔法（技能类型 1） |
| 4 | 8 束缚·目 | QTE 条几乎看不清 |
| 5 | — | 完全束缚 → HP 归零 → 战败 |

- 束缚等级存在**变量 11**，只读镜像，事件里可以直接判断。
- 解除：QTE 成功一次解除「被抓」状态；束缚等级本身需要专门的道具/事件（待设计）。

## 三、QTE

- **触发**：敌人技能命中薇薇且带 `<grab>` 注释。
- **形式**：横向游标在 480px 的条上来回移动，按 OK 判定；中间绿色区间是成功范围。
- **成功区间**：
  - 法师 96px / 魔剑士 150px
  - 色情条每 1 点 −0.35px
  - 束缚每级 −14px
  - 下限 28px
- **游标速度**：7 + 色情条×0.06 + 束缚等级×1.5（px/帧）
- **超时**：180 帧（3 秒）未按 = 失败。
- **失败**：束缚等级 +1。
- **遮挡**：束缚 ≥4 时，条和游标都画成半透明，"视线被遮住了"。

## 四、色情条

- 存在**变量 10**（0–100），战斗开始时归零。
- 敌人技能带 `<lewd:N>` 命中时 +N。
- **发情 / 敏感 / 媚药**三个状态各自把增量 ×1.5（可叠加）。
- **满 100** → 附加「高潮」状态（一回合无法行动），然后**回落到 30**（不是归零）。
- 战斗界面右上角显示数值 + 一条进度条。

## 五、我留空、你填写的部分

| 位置 | 标签 | 说明 |
|---|---|---|
| 技能 9「触手缠绕」的 `message1` | `【EV-1-01】` | 战斗日志里的那一句 |
| 战败 CG / 场景 | `【CG-xx】` | 用占位事件结构，见《内容分工与占位符规范》 |

技能 9 现在长这样：

```
%1 的触手缠了上来……【EV-1-01】
```

你把 `【EV-1-01】` 换成你的文本就行。要加新的色情攻击技能，复制技能 9，
改 `<lewd:N>` 的数值和 `message1` 即可。

## 六、注释标签速查

```
<grab>        命中薇薇 → 触发 QTE
<lewd:25>     命中薇薇 → 色情条 +25
<restraint:2> 命中薇薇 → 束缚等级直接设为 2
```

写在技能（或敌人动作）的**注释**栏里。
