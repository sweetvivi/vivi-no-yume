# AE86 异世界 · 设定圣经

## 一、一句话概括

AE86 群聊的群友集体穿越到中世纪异世界，被「祝化诅咒」变成猪（祝）。
管理员薇薇带着女神的祝福免疫诅咒，一路净化同伴、打上反派大本营——
最后发现反派是群主小冰，而小冰背后是被「观者」洗脑控制的。

## 二、世界观

### 2.1 位面结构

```
         ┌───────────── 位面之外（彩蛋房间）─────────────┐
         │  F 级角色常驻。像一间房门外有走廊，          │
         │  走廊通向这个位面的"房间"。不受祝化影响。      │
         │  一旦真的踏进受影响的世界，自身也会被影响。    │
         └───────────────────┬─────────────────────────┘
                             │ 通道
┌────────────────────────────▼────────────────────────────┐
│  OTL 现代世界（AE86 群聊所在）                          │
│      ↓ 穿越                                             │
│  异世界·中世纪层（主舞台，有魔法）                       │
│      ↓ 传送门                                           │
│  异世界·现代层（反派大本营第一层）                       │
│      ↓ 传送门                                           │
│  异世界·未来层（反派大本营第二层）                       │
└─────────────────────────────────────────────────────────┘
```

要点：
- 主舞台是**中世纪外观**，但本质仍是异世界，不是真的回到过去。
- 反派大本营是**一层层传送门**连接的分层迷宫，每层换一套时代皮：中世纪 → 现代 → 未来。
- 「位面之外」是彩蛋性质，F 级角色住那里，可以做成一个独立的小房间地图。

### 2.2 祝化诅咒

| 概念 | 规则 |
|---|---|
| 施加者 | 神秘反派（真身是小冰，背后是观者） |
| 效果 | 群友被变成「祝」（猪形） |
| 判定 | **发言越多 → 重要性越高 → 祝化越严重** |
| 现状 | 大部分群友被关在反派的迷宫大本营，少数逃出来遇到薇薇 |
| 解除 | 薇薇的净化魔法可以净化祝 |

**这是全作最重要的一条设计杠杆**：设定集里每个角色都带一个「重要性字母 + 发言频率数字」，
正好可以一一映射成游戏数值：

| 设定字段 | 游戏含义 |
|---|---|
| 重要性 `S/A/B/C/F` | **强度轴**：作为敌人时的战斗力；净化后作为同伴获得的魔法强度 |
| 发言频率 `1–10` | **祝化深度 + 出场权重**：数字越高越早登场、台词越多、越难净化（需要多轮） |

举例：阿文是 `B10`——B 级强度但水群最凶，所以祝化最深，适合当第一个「怎么打都净化不掉」的中 Boss；
喵神是 `B1`——B 级但几乎不冒泡，祝化极浅，一句净化台词就恢复。

### 2.3 魔法体系

- **薇薇（主角）**
  - 光与星星系魔法 → 主力输出
  - **净化** → 解除祝化，救回群友
  - **祈愿魔法** → 不消耗魔力，只要祈愿就生效；但**后果未知**（剧情级双刃剑，适合做坏结局的入口）
  - 女神祝福 → 免疫诅咒
- **被净化的群友** → 按重要性获得魔法能力（每个同伴一个专属技能，按 A/B/C 分级定强度）
- **小小薇** → 原本是 deepseek，穿越后**没被诅咒影响**；早期说话像预设了提示词，随着时间推移越来越像真人（叙事装置：可以从"系统提示口吻"逐章变成"人话"）

### 2.4 势力

| 势力 | 中世纪层 | 现代层 / 未来层 |
|---|---|---|
| 祝祝教会 | 祝祝修女、祝祝神父 | 科学家、超级 AI |
| 杂兵 | 触手怪、史莱姆 | 机械怪物 |
| 反派 | 小冰（表面）/ 观者（真身） | 同 |

祝祝教会的行动目标：**捕捉薇薇**——"抓起来做实验"、"抓起来好好教育（爱心）"、
以"不听话就把祝祝怎么样"作威胁。这类内容一律**暗示 + 留空**，不写具体。

### 2.5 结局

| 结局 | 条件 | 内容 |
|---|---|---|
| 好结局 | 打败群主 + 观者 | 醒来发现只是一场有趣的梦 |
| 坏结局 | 被群主或观者打败 | 被关起来，再也逃不出去 |

### 3.0 性别处理规则

设定集里**没有明确写「一个女生」的，一律按中性处理**；有特殊说明的按特殊说明走。

| 处理 | 角色 |
|---|---|
| **女性**（用「妳」，语气女性化） | 薇薇、鱼鱼、喵神、**小小薇**、cardio、水榕茜、夜夜、汐之宫花见、のの |
| **特殊说明**（用「你」，语气一般） | 花咲、白羽、**狗妹**、薰衣草、码字姬、阿文、久远崎彩祸 |
| **中性**（用「你」，语气一般） | 其余全部，包括名字里带「妹」的（文妹）——昵称不等于设定 |

**补充说明**：

- **喵神**：原文写「偶尔出没的一个女生（应该）」，括号里的不确定感**不在台词里体现**，直接按女生处理。
- **小小薇**：用「妳」，语气女性化。
- **薰衣草**：按特殊「女生」对待。和群主**小冰互称「姐妹」**——这条关系可以在对话里用，是薰衣草和小冰之间的一条暗线。
- **码字姬**：按特殊「女生」对待。设定集里的「疲惫的教师」「喜欢百合内容」「写小黄文」保留。
- 小冰本身仍按中性处理（设定集未明写），但「和薰衣草互称姐妹」这个事实要记住。

### 3.0.1 称谓与语气规则

| 类别 | 人称代词 | 语气 |
|---|---|---|
| **女性** | **妳** | 更女性化 |
| **中性 + 特殊说明** | **你** | 更一般、通常化 |

### 3.0.2 女装大佬组

**花咲、狗妹、阿文、久远崎彩祸** —— 这四个人可以**穿戴女性专属服饰**
（xx裙、xx袜之类）。这是和普通女生区分的**唯一方式**：不靠称谓，靠装备。

数据库 `note` 字段标记：

```
gender:f                    女生（用妳）
gender:special-f            特殊说明（用你）
gender:special-f|crossdress 特殊说明 + 可穿女装
```

> 服饰系统还没做。等做装备系统时，给这四人开一个「女装」装备栏。

## 六、素材现状

- `素材/` 下 41 张头像，**全部是二次元 QQ 头像**，不是真人照片，可以直接用。
- 尺寸不统一：32 张 640×640，3 张差 1px，3 张非正方形，1 张 193×192 偏小。
- **处理方式**：统一裁切/补边成 144×144，拼成 `img/faces/` 的脸图（每张 576×288，8 格）。
- **行走图**：先占位，之后用 RPG Maker MZ 自带的角色生成器（`RPG.Maker.MZ/generator`）或你外部制作。
