# ヴィヴィの夢 / 薇薇的梦

一个用 **RPG Maker MZ** 制作的同人 RPG。AE86 群聊的群友们某天夜里被卷进了另一个世界——一座不断向上延伸的塔。

> 深夜里，群里有人说了句「都别走，我找到了一个好东西」。
> 然后所有人都醒了，在一个陌生村庄，回不去了。

## 故事

薇薇是 AE86 群的管理员，被大家叫「魔法少女」「小蛋糕」。

一天深夜，群友小冰在群里发了一条消息，然后所有人都失去了意识。醒来时人在中世纪的村庄，而群友们一个接一个变成了没有意识的「祝」。

薇薇是唯一不受祝化影响的人——她能净化别人。

于是她一层一层往上走，把散落的群友一个个捡回来，直到塔顶那个说「我只需要知道数值」的存在面前。

## 系统

几个做了点额外设计的地方：

**束缚与 QTE**
被敌人抓住后进入束缚状态，要连打确定键挣脱。区间会随「色情条」和束缚等级收窄——越晚挣脱越难。队友可以辅助解缚，比自救容易得多。

**魔剑士形态**
TP 攒满 100 可以用「剑心·转」切换形态。法师形态攻击力 ×0.35，剑形态 ×2.0，但剑形态只有 3 回合。什么时候切换是核心决策。

**服装与回避**
防具直接影响回避率。薄纱衣 +20%，铁铠 **−25%**（负数意味着完全无法回避，但也意味着高防御）。穿什么会改变整场战斗的手感。

**女装**
带 `crossdress` 标签的防具只有特定角色能穿。

**观者姿态**（终章）
致敬 [杀戮尖塔](https://store.steampowered.com/app/646570/) 的观者：愤怒（伤害 ×2，但自己也受 ×2 伤害）、神格（攒满 10 层真言，伤害 ×3）。

**祈愿**
零消耗的全体大伤害，但有 30% 概率什么都不会发生。

## 开发

```
git clone https://github.com/sweetvivi/vivi-no-yume.git
```

用 **RPG Maker MZ** 打开 `game.rmmzproject` 即可编辑。

| 位置 | 用途 |
|---|---|
| `data/` | 数据库与地图（MZ 标准格式） |
| `js/plugins/AE86_Systems.js` | 核心自定义系统（形态 / 束缚 / QTE / 观者姿态） |
| `docs/` | 设定、战斗系统、进度、交接说明 |
| `tools/` | 开发用脚本（批量建事件、修数据、校验） |

⚠️ 仓库不含 NW.js 运行时（`Game.exe`、`*.dll` 等）。要打包成可执行文件，用 MZ 的「文件 → 部署 → Windows」。
